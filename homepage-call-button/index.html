홈페이지 전화 버튼 위치

홈페이지의 목적은 결국 연락입니다. 전화·문자 버튼을 어디에, 어떻게 두면 더 많이 눌리는지 정리했습니다.

눌리는 버튼의 조건

  • 휴대폰 화면 아래에 늘 보이게 고정
  • 엄지손가락으로 누르기 쉬운 크기
  • '전화하기'처럼 할 일이 분명한 글자
  • 누르면 바로 전화가 걸리게(번호를 따로 입력하지 않게)

전화만 두지 마세요

전화가 부담스러운 손님도 많습니다. 문자, 카카오톡, 사진 보내기 버튼을 함께 두면 전화로는 연락하지 않았을 손님까지 문의합니다. 특히 문의 내용을 미리 채워 주는 문자 버튼은 손님의 수고를 크게 줄여 줍니다.

효과 확인하기

웹 스튜디오의 방문 통계를 쓰면 전화 버튼과 문자 버튼이 각각 몇 번 눌렸는지 볼 수 있습니다. 숫자를 보고 버튼 위치나 문구를 바꿔 가며 다듬습니다.
