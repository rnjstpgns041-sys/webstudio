검색 결과 제목 설명 문구

검색 결과에 보이는 제목과 설명 한 줄이 손님의 클릭을 결정합니다. 검색 결과 문구를 잘 쓰는 방법입니다.

검색 결과에 보이는 것

네이버와 구글 검색 결과에는 페이지 제목과 짧은 설명이 보입니다. 이 문구는 홈페이지 안에 따로 적어 둘 수 있고, 적어 두지 않으면 검색 회사가 본문에서 아무 문장이나 가져옵니다.

잘 쓴 제목과 설명

  • 제목: 손님이 검색하는 말 + 가게 이름 (예: 속초 생선찜 | 대포항생선찜본점)
  • 설명: 손님이 얻는 것과 행동 한 줄 (예: 사진 보내면 당일 견적)
  • 페이지마다 다르게
  • 너무 길지 않게(제목 30자, 설명 80자 안팎)

웹 스튜디오의 방식

모든 페이지에 검색 결과용 제목과 설명을 따로 써 넣습니다. 서치어드바이저에서 클릭이 적은 페이지는 문구를 바꿔 가며 다듬습니다.
