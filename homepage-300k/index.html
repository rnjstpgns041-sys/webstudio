30만원 홈페이지 제작 어디까지

30만원 안팎이면 휴대폰에서 잘 보이는 한 장짜리 가게 소개 홈페이지를 만들 수 있습니다. 웹 스튜디오의 '한 장 소개'는 29만원이고, 매달 내는 관리비 없이 시작할 수 있습니다.

29만원 한 장 소개에 들어가는 것

  • 휴대폰에 맞춘 한 페이지 홈페이지
  • 가게 소개, 대표 사진, 서비스·메뉴 안내
  • 전화·문자 바로 걸기 버튼, 오시는 길
  • 네이버·구글 검색 등록
  • 무료 주소로 바로 공개 (가게 이름 주소는 연 2만원 안팎 별도)

이런 분께 맞습니다

처음 홈페이지를 만드는 가게, 플레이스와 블로그는 있는데 링크 하나로 가게를 보여 주고 싶은 분, 명함과 전단지에 넣을 주소가 필요한 분께 맞습니다.

업종별 안내 페이지를 여러 개 두어 검색에서 더 많이 걸리게 하고 싶다면 기본 홈페이지(59만원)나 검색 노출형(89만원)이 낫습니다. 나중에 올려 갈 수도 있습니다.

싼 제작에서 확인할 것

  • 매달 관리비를 꼭 내야 하는지
  • 가게 이름 주소가 사장님 명의인지
  • 그만둘 때 사이트를 가져갈 수 있는지
  • 수정 요청은 몇 번, 언제까지 되는지

웹 스튜디오는 월 관리비가 필수가 아니며, 무료 수정 기간 뒤 원하실 때만 월 3만원으로 수정 관리를 맡기실 수 있습니다.
