어르신 손님이 보기 쉬운 홈페이지

손님 중에 어르신이 많다면 글자 크기와 버튼 하나까지 달라야 합니다. 어르신도 편하게 보는 홈페이지를 만드는 방법입니다.

이렇게 만듭니다

  • 글자는 크게, 줄 간격은 넉넉하게
  • 어려운 외래어 대신 쉬운 우리말
  • 전화 버튼은 크고 화면 아래에 늘 보이게
  • 한 화면에 한 가지 내용만
  • 누르면 바로 전화가 걸리는 번호

자녀가 대신 찾아보는 경우

어르신을 위한 서비스(보험, 집수리, 반찬 배달 등)는 자녀가 대신 검색하는 경우도 많습니다. 자녀가 부모님께 링크를 보내 드리기 좋게 주소를 짧고 쉽게 정하는 것도 중요합니다.

웹 스튜디오의 방식

웹 스튜디오는 모든 사이트를 휴대폰 화면부터 만들고, 전화 버튼을 크게 둡니다. 어르신 손님이 많다고 말씀해 주시면 글자를 더 키우고 내용을 더 간단히 정리합니다.
