홈페이지 만들기

홈페이지를 처음 만든다면 무엇부터 해야 할까요? 가게 사장님 기준으로 홈페이지 만드는 순서를 처음부터 끝까지 정리했습니다.

홈페이지 만드는 순서

  • 목적 정하기: 전화 문의, 예약, 방문 중 무엇을 늘리고 싶은지
  • 내용 모으기: 소개 문구, 사진, 가격, 연락처
  • 만드는 방법 고르기: 직접 만들기, 홈페이지 빌더, 맡기기
  • 주소 정하기: 무료 주소 또는 가게 이름 주소
  • 휴대폰 화면 확인 후 오픈
  • 네이버·구글 검색 등록

가장 많이 하는 실수

예쁜 디자인부터 고민하다 정작 손님이 궁금한 가격, 위치, 연락 방법을 빠뜨리는 경우가 많습니다. 손님이 전화하기 전에 묻는 질문 다섯 개에 답하는 것부터 시작하세요.

맡기면 달라지는 것

웹 스튜디오에 맡기시면 사진과 설명만 보내 주시면 됩니다. 휴대폰 화면부터 만들어 링크로 보여 드리고, 오픈하는 날 검색 등록까지 마칩니다.

며칠이면 만들 수 있나요?

자료가 준비돼 있으면 한 장 소개는 며칠, 기본 홈페이지는 1~2주 정도 봅니다.
